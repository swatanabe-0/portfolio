# Portfolio — 渡辺翔太 / Watanabe Shota

就職活動用のポートフォリオサイトです。**「実績が少ないなら、サイト自体を成果物にする」** ことを目標に制作しました。

- 情報は、確実に読める層に置いています。
- 触って遊べる要素（物理演算で動く文字とバッジ、ミニデモ、ターミナル）は、別の層に分けています。
- 閲覧者の立場（人事 / 現場エンジニア / 経営）を選ぶと、並び順と文言が変わります。

## 主な機能

| 機能 | 内容 |
|---|---|
| ロール選択 | 立場に合わせて、セクションの並びと文言を切り替える |
| Hero | 名前の文字が物理演算で落ちる。カーソルで散らせて、一定時間後に自動で整列する |
| Skills | バッジを掴んで投げられる。クリックで、その技術のミニデモとコードが開く |
| Experience / Works | 経験と、このサイトの制作過程を掲載 |
| ターミナル | `/` キーで開く。`help` でコマンド一覧が出る |
| Quick Resume | 1分で読める要約 |

## 使用技術

- [Vite](https://vite.dev/)
- [GSAP](https://gsap.com/) / ScrollTrigger
- [Lenis](https://lenis.darkroom.engineering/)（慣性スクロール）
- [Matter.js](https://brm.io/matter-js/)（2D物理演算）
- [Three.js](https://threejs.org/)（ミニデモのみ。クリック時に遅延読み込み）
- HTML / CSS / JavaScript（フレームワークなし）

## 動かし方

Node.js が必要です。

```bash
npm install
npm run dev
```

ブラウザで、表示されたURL（通常は `http://localhost:5173`）を開きます。

本番用のビルドは次の通りです。

```bash
npm run build
```

`dist/` に出力されます。

### 開発用のURLパラメータ

| パラメータ | 動作 |
|---|---|
| `?role=hr` / `engineer` / `exec` / `all` | ロール選択を飛ばして、その立場の表示で開く |
| `?noboot` | ブート演出を省略する |

## ファイル構成

```
index.html   ページの構造と文章
style.css    見た目
main.js      動き・物理演算・ミニデモ・ターミナル・ロール別表示
```

文言（スキルの説明、ロール別の文面など）は、`main.js` の先頭にある `SKILLS` と `ROLES`、`index.html` の各セクションにまとめています。

## 制作について

方向性の検討と実装には AI（Claude・Gemini）を使い、案の取捨選択と動作確認は自分で行いました。制作過程は、サイトの Works に載せています。

## 注意

- 検索エンジンに載せない設定（`noindex`）を入れています。
- 長期インターンの内容は、守秘義務のため概要のみを掲載しています。
